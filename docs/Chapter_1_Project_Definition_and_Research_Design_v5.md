# فصل اول — تعریف پروژه و طرح پژوهش

**عنوان پروژه:** تحلیل تغییرات دیدگاه کاربران مشاهده‌شده در X، Reddit و YouTube درباره مناقشه ایران و آمریکا
**بازه پروژه:** `2026-02-28` تا `2026-07-22`  
**هفته‌ها:** `W01` تا `W21`؛ هفته `W21` پنج روزه است.

---

## ۱. هدف پژوهش

هدف پروژه اندازه‌گیری روند محتوای منتشرشده درباره مناقشه ایران و آمریکا در 
نمونه‌های قابل‌دسترسی X، Reddit و YouTube و بررسی ارتباط این روند با رویدادهای مهم و چند شاخص مالی منتخب است. 
واحد اصلی تحلیل یک محتوای متنی مستقل و واجد شرایط است.

این مطالعه نظرسنجی از جمعیت جهان نیست. دامنه استنباط به محتوای عمومی بازیابی‌شده با روش ثبت‌شده در این پروژه محدود است.

### ۱.۱ حاکمیت داده و نسخه‌های پروتکل

جمع‌آوری X، Reddit و YouTube براساس Schema و Query Registry تخصیص‌یافته به هر Collector انجام می‌شود. برای حفظ قابلیت ممیزی و تکرارپذیری، قواعد زیر در تمام مراحل پروژه رعایت می‌شوند:

- نسخه Schema و Query Registry مرتبط با هر Collection Run ثبت می‌شود.
- فایل خام بدون تغییر نگهداری و Cleaning در لایه جداگانه انجام می‌شود.
- Query، Source، Sort، Cap، Pagination و Data cutoff براساس Manifest واقعی همان Run گزارش می‌شوند.
- مقدار فاقد شواهد با `unknown` ثبت می‌شود و از روی حدس تکمیل نمی‌شود.
- تبدیل نام یا نوع ستون‌ها در لایه `raw_harmonized` انجام می‌شود.
- طرح Annotation و تحلیل آماری پیش از تولید خروجی نهایی قفل و تغییرات در Decision Log ثبت می‌شوند.

بازه رسمی مطالعه در `2026-07-22` پایان می‌یابد. Coverage 
واقعی هر پلتفرم با حداقل و حداکثر Timestamp مشاهده‌شده تعیین
و آخرین زمان موجود با عنوان `observed_data_cutoff` گزارش می‌شود.

## ۲. پرسش اصلی

> سهم احساس، موضع، هیجان و موضوع در محتوای واجد شرایط مشاهده‌شده در X، Reddit و YouTube طی بازه پروژه
> چگونه تغییر کرده است و این تغییرات چه ارتباط زمانی با 
> رویدادهای ثبت‌شده و تغییرات شاخص‌های مالی منتخب داشته‌اند؟

## ۳. پرسش‌های فرعی

1. حجم نظرات واجد شرایط در هر هفته چقدر بوده است؟
2. سهم برچسب‌های Sentiment و Stance در طول زمان چگونه تغییر کرده است؟
3. آیا تغییر روند پس از کنترل ترکیب پلتفرم، منبع، زبان، نوع محتوا و نویسندگان پرتکرار باقی می‌ماند؟
4. آیا در پنجره‌های از پیش تعیین‌شده پیرامون رویدادهای اصلی، تغییر قابل‌اندازه‌گیری مشاهده می‌شود؟
5. آیا تغییرات هفتگی نگرش با بازده یا تغییر هفتگی شاخص‌های مالی منتخب ارتباط دارد؟
6. حذف Duplicate، متن‌های بسیار مشابه، محتوای پرریسک و برچسب‌های کم‌اطمینان چه اثری بر نتیجه دارد؟

## ۵. واحدهای تحلیل

| واحد | کاربرد | شناسه |
|---|---|---|
| Post/Comment/Reply/Quote | واحد اصلی تحلیل نگرش، در صورت داشتن متن مستقل | `platform_content_id` |
| Author | کنترل مشارکت تکراری، در صورت دسترسی | `author_hash` |
| Parent content | زمینه بحث و واحد خوشه‌ای دوم | `source_parent_id` |
| Source | Subreddit، Channel یا Conversation | `source_id` |
| Project Week | گزارش روند | `project_week` |
| Collection Run | ممیزی جمع‌آوری | `collection_run_id` |

نوع محتوا و پلتفرم همیشه حفظ می‌شود. 
نتیجه هر پلتفرم ابتدا جداگانه محاسبه می‌شود؛ تجمیع سه پلتفرم فقط در تحلیل ثانویه و با گزارش ترکیب نمونه انجام می‌شود.

- پایان: ۳۱ تیر ۱۴۰۵، برابر با `2026-07-22`

`W21` از `2026-07-18` تا `2026-07-22` ادامه دارد. 
حجم خام آن با هفته‌های هفت‌روزه مقایسه نمی‌شود؛ سهم‌های نگرشی با `n` و علامت هفته ناقص گزارش می‌شوند.

## ۷. پلتفرم و زبان

X، Reddit و YouTube سه محیط مکمل اما غیرهم‌ارز هستند. دلیل انتخاب، مسیر دسترسی و Biasهای اختصاصی آن‌ها در فصل سوم ارائه شده است. نتیجه هر پلتفرم ابتدا جداگانه گزارش می‌شود.

زبان اصلی تحلیل انگلیسی است. متن فارسی و سایر زبان‌ها حذف نمی‌شوند، اما تحلیل جداگانه یک زبان فقط زمانی انجام می‌شود که حجم نمونه 
و کیفیت مدل برای آن زبان کافی باشد. زبان متن به‌عنوان کشور نویسنده تفسیر نمی‌شود.

## ۸. متغیرهای نگرشی

### ۸.۱ Sentiment

لحن عمومی متن:

`positive` · `negative` · `neutral` · `mixed` · `unclear`

### ۸.۲ Stance

موضع نسبت به Target مشخص:

`support` · `oppose` · `neutral_or_balanced` · `unrelated` · `unclear`

Targetهای اصلی:

| Target ID | Target |
|---|---|
| `T01` | اقدام نظامی یا تشدید درگیری |
| `T02` | مذاکره، آتش‌بس و دیپلماسی |
| `T03` | تحریم و فشار اقتصادی |
| `T04` | سیاست یا اقدامات دولت ایران |
| `T05` | سیاست یا اقدامات دولت آمریکا |
| `T06` | پیامدهای انسانی و حفاظت از غیرنظامیان |

یک متن می‌تواند برای بیش از یک Target برچسب داشته باشد. Sentiment جایگزین Stance نیست.

### ۸.۳ Emotion

`anger` · `fear` · `sadness` · `hope` · `other` · `none_or_unclear`

### ۸.۴ Content Type

`personal_opinion` · `news_or_report` · `quotation` · `satire` · `spam` · `unclear`

### ۸.۵ Topic

`military_security` · `diplomacy` · `sanctions_economy` · `humanitarian` · `energy` · `media_information` · `domestic_politics` · `international_reaction` · `other`

## ۹. خلاصه طرح آماری

طرح آماری کامل در فصل دوم تعریف شده است. مسیر تحلیل شامل مراحل زیر است:

| مرحله | خروجی اصلی |
|---|---|
| کیفیت داده | Record flow، Missing، Duplicate و Coverage |
| ارزیابی Annotation | توافق انسانی، Confusion Matrix و Macro-F1 |
| توصیف نمونه | حجم، ترکیب Platform/Language/Source و توزیع Labelها |
| روند زمانی | سهم هفتگی همراه با `n` و فاصله اطمینان ۹۵٪ |
| مقایسه گروه‌ها | آزمون متناسب، Effect size و بررسی فرض‌ها |
| تحلیل رویداد | اختلاف Windowهای ثبت‌شده و تحلیل حساسیت |
| تحلیل مالی | بازده هفتگی، Lagهای ثبت‌شده و اصلاح FDR |
| پایداری نتیجه | تحلیل با و بدون تکرار، محتوای پرریسک، Confidence پایین و منابع غالب |

فصل دوم مرجع اندازه Gold Sample، روش محاسبه عدم قطعیت، آزمون‌ها و تحلیل‌های حساسیت است. `event_registry_v3.md` مرجع انتخاب رویداد و Windowهاست.

## ۱۰. مرز تفسیر

نتیجه‌ها توصیفی و ارتباطی‌اند. تغییر مشاهده‌شده ممکن است از تغییر نگرش، تغییر ترکیب نمونه، تغییر دسترسی یا تغییر روش جمع‌آوری ناشی شود.
هر ادعای اصلی باید همراه با حجم نمونه، عدم قطعیت، تحلیل ترکیب و تحلیل حساسیت ارائه شود.

| عبارت قابل استفاده | عبارت غیرقابل استفاده |
|---|---|
| «در محتوای واجد شرایط مشاهده‌شده در X، Reddit یا YouTube...» | «افکار عمومی جهان نشان داد...» |
| «میان رویداد و تغییر مشاهده‌شده همراهی زمانی وجود داشت.» | «رویداد باعث تغییر نگرش شد.» |
| «در داده بازیابی‌شده با Queryها و Sourceهای ثبت‌شده...» | «همه کاربران پلتفرم چنین نظری داشتند.» |
| «تفاوت میان نمونه‌های سه پلتفرم مشاهده شد.» | «مردم سه جامعه با هم متفاوت‌اند.» |
