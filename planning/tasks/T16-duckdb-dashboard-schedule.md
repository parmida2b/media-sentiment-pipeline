## تغییر
1. خروجی تحلیلی: parquet پارتیشن‌شده بر اساس `platform` و `project_week` + `scripts/query.py` یا یک فایل `.duckdb` با viewهای آماده (روند هفتگی، پوشش، رویدادها).
2. داشبورد: `src/reporting/build_dashboard.py` و `dashboard_template.html` موجودند؛ نمودار روند هفتگی سه پلتفرم با CI، خطوط رویداد، جدول پوشش، تاریخ آخرین به‌روزرسانی. بدون متن کاربر.
3. انتشار ایستا با GitHub Pages (workflow).
4. workflow زمان‌بندی‌شده‌ی هفتگی: YouTube افزایشی + مالی + annotation افزایشی با سقف + بازسازی داشبورد. secrets در GitHub Actions توسط خود کاربر تنظیم شود.
